Тестовое задание для AQA

Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```

Что исправлено
--------------

1. `BUTTON_WRITE_TO_US`: селектор `[class^=btn]` находил несколько элементов (кнопки «помогла / не помогла» и др.), поэтому клик падал из-за strict mode. Заменён на `[data-test=button_feedback_form]`.
2. `getPopularArticles()`: метод `.all()` не ждёт загрузки списка и мог вернуть пустой массив, тогда `articles[0]` = `undefined`. Тест `has correct title` падал с `TypeError: Cannot read properties of undefined (reading 'click')`. Теперь метод возвращает локатор, а тест кликает `.first()` - Playwright сам ждёт появления элемента.
3. `getTitle()`: `textContent()` читал заголовок сразу после клика, до смены экрана. Теперь возвращает локатор, проверка через `expect(...).toHaveText()` с автоожиданием.
4. Убран неиспользуемый параметр `page` в тестах.

`returns to knowledge base from article by back button` - открывает статью из списка популярных и проверяет, что кнопка «Назад» возвращает в базу знаний со списком статей.
